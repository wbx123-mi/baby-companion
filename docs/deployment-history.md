## 小程序发布规则

1. 执行 `pnpm build:miniapp:production`，成功后自动生成 `.release/miniapp-pending.json`。
2. 将 `apps/miniapp/dist/build/mp-weixin` 上传至微信开发者工具。
3. 在微信后台完成体验版或正式版发布。
4. 发布成功后执行：

   ```bash
   pnpm release:confirm:miniapp <微信版本号> <experience|production> [备注]
   ```

5. 检查并提交本文件新增的发布记录。

发布前应保持 Git 工作区干净。若待发布记录显示包含未提交改动，该版本无法仅依靠 Commit 精确还原。
